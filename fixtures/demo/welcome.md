# Welcome to Lockerly

This is a shared demo drive. Try anything:

- **Upload** by dropping files anywhere, or with **New**
- **Open** a file to preview it, and step through a folder with the arrow keys
- **Share** a folder with Sam, or make a public link
- **Search** with `/`, and see everything that happened under **Activity**

Everyone who tries the demo uses this drive, and it goes back to how it was once a day.
